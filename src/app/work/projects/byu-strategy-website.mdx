## Overview

I'm the product owner and builder for the redesign of [strategy.byu.edu](https://strategy.byu.edu), the website for the **Strategic Management program** at BYU's Marriott School of Business. I work with the program director.

## The problem

The program's site has to do two jobs: explain the program to prospective students, and move them toward applying. For a cycle with **301 applicants**, the old site wasn't organized around the questions prospects actually have.

## What I did

- Rebuilt the site into a **six-page, prospect-first application funnel**: curriculum, career tracks, placement data and alumni network, leading to the application.
- Shipped the redesign through **GitHub Flow**: feature branches for each phase, reviewed on **Vercel preview** deployments before merging.
- Kept every existing public URL working through the redesign.

## Skills

Product ownership · Information architecture · Conversion-focused design · Next.js · GitHub Flow and Vercel previews · Stakeholder management
